Общие правила по листочкам:

  • Сдавая решение задачи до дедлайна, Вы получаете полный балл, а после — лишь половину; через неделю после дедлайна происходит разбор, после которого ничего сдавать нельзя
  • Решения задач сдаются в устной форме одному из принимающих; в исключительных случаях (по причине болезни, например), возможна сдача письменно по электронной почте в формате TEX
  • Решивший все задачи из листочка может получить и сдавать дополнительные задачи
  • Прием задач осуществляется ВНЕ помещений лаборатории Чебышева
