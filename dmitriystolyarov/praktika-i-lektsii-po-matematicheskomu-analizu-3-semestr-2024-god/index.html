Правила получения зачёта:

Для получения зачета по математическому анализу необходимо решить все
задачи всех контрольных и решить не менее 2х задач из каждого листка с
теоретическими задачами по курсу лекций.


Правила начислений рейтинга:

70 баллов рейтинга даются за решение рейтинговой части листочка.
Рейтинг студента S вычисляется по формуле \Sigma_S/\Sigma_{Max}, где
\Sigma_{S} — суммарная стоимость задач, решенных S, а \Sigma_{\Max} —
максимум величины \Sigma_S по всем S. Цена задачи Z вычисляется по
формуле N_{all} + K_Z\cdot N_{UnSolve}, где N_\all — общее число
студентов, N_{UnSolve} — число студентов, не решивших Z, а K_Z \in
[1,3] — индивидуальный коэффициент задачи (устанавливается заранее).
Не рейтинговые задачи листочка баллов не приносят!

Оставшиеся 30 баллов даются за  4 самостоятельные  и 2 контрольные работы.
