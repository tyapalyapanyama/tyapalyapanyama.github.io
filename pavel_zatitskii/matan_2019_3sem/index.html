Общие правила:

  • Сдавая решение задачи до наступления «срока сдачи», можно получить полный балл. После наступления «срока сдачи» баллы за задачи делятся пополам.
  • Решения задач сдаются в устной форме одному из принимающих; в исключительных случаях (по причине болезни, например), возможна сдача письменно по электронной почте в формате PDF (скомпилированный из TEX).
  • Решивший все задачи из листка до «срока сдачи» может получить и сдавать дополнительные задачи.
  • В каждом листке некоторые задачи можно сдавать только преподавателям.
  • Теоретическая контрольная работа пишется каждым студентом 1 раз, без переписывания.
  • Прием задач осуществляется ВНЕ помещений лаборатории Чебышева.
  • Рейтинговые баллы выставляются начиная с 60.
    В случае, если набрано меньше 60 баллов, в рейтинг идет 0.
